# Practicamos: ¿Qué tiempo hace?

¡Ponte el abrigo o coge el bañador según corresponda! Vamos a practicar lo aprendido.

## Ejercicio 1: Relaciona cada clima con sus características

Une con flechas el tipo de clima con lo que pasa en él:

1. Clima Oceánico       ->   ( Temperaturas suaves todo el año y llueve muchísimo )
2. Clima Mediterráneo   ->   ( Nieva mucho en invierno y hace mucho frío )
3. Clima Subtropical    ->   ( Veranos muy calurosos e inviernos secos )
4. Clima de Montaña     ->   ( Temperaturas cálidas todo el año, como en Canarias )

## Ejercicio 3: Verdadero o Falso

Indica si es Verdadero (V) o Falso (F). Corrige las falsas.

1. [ ] El clima Mediterráneo es el que ocupa menos territorio en España.
