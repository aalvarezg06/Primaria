# Practicamos: ¡En Forma y Sanos!

Vamos a comprobar si sabes cómo cuidar de tu cuerpo para estar sano y fuerte.

## Ejercicio 1: Hábitos Saludables vs Hábitos Nocivos

Dibuja una carita sonriente (😊) al lado de los hábitos saludables y una carita triste (☹️) al lado de los hábitos perjudiciales.

1. Comer fruta para merendar. (   )
2. Lavarse los dientes solo por las mañanas. (   )
3. Dormir 10 horas todas las noches. (   )
4. Jugar 3 horas seguidas con la consola sin moverse del sofá. (   )
5. Lavarse las manos antes de comer. (   )
6. Beber muchos refrescos azucarados en lugar de agua. (   )

## Ejercicio 2: Elige la mejor opción

Rodea la opción más saludable para cada situación:

*   **Para el recreo:** a) Un bollo de chocolate / b) Un plátano y un pequeño bocadillo.
*   **Si estoy aburrido el sábado:** a) Salir al parque a jugar / b) Ver la tele toda la tarde.
*   **Si un amigo me insulta:** a) Le insulto yo a él más fuerte / b) Se lo digo a un profesor para solucionarlo hablando.
