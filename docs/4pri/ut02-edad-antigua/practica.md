# Practicamos: La Edad Antigua

¡Demuestra que eres un gran historiador de la antigüedad!

## Ejercicio 1: ¿Egipcios, Griegos o Romanos?

Escribe al lado de cada frase a qué civilización se refiere:

1. Construían grandes pirámides para enterrar a los faraones. -> ____________________
2. Construyeron acueductos, calzadas y el Coliseo. -> ____________________
3. Inventaron los Juegos Olímpicos y la democracia. -> ____________________
4. Hablaban en latín. -> ____________________
5. Escribían utilizando jeroglíficos (dibujos). -> ____________________

## Ejercicio 2: El intruso

En cada lista hay una palabra que NO pertenece a esa civilización. Táchala o escríbela al lado.

* **Egipcios:** Faraón - Nilo - Momia - Acueducto - Jeroglífico. (Intruso: ______________)
* **Griegos:** Polis - Atenas - Juegos Olímpicos - Gladiador - Filosofía. (Intruso: ______________)
* **Romanos:** Legión - Pirámide - Latín - Hispania - Emperador. (Intruso: ______________)
