# Practicamos: Bajo el Microscopio

¡Ponte la bata de científico y vamos a comprobar cuánto sabes sobre las células!

## Ejercicio 1: Completa las frases

Rellena los huecos con estas palabras: **microscopio**, **unicelulares**, **cloroplastos**, **núcleo**.

1. A los seres vivos formados por una sola célula los llamamos ____________________.
2. El aparato que utilizamos para poder ver las células se llama ____________________.
3. El "cerebro" que dirige el funcionamiento de la célula es el ____________________.
4. Las células vegetales tienen unos orgánulos especiales llamados ____________________ que sirven para hacer la fotosíntesis.

## Ejercicio 2: ¿Animal o Vegetal?

Lee las características e indica si nos referimos a una Célula Animal (A) o a una Célula Vegetal (V).

*   [ ] Tienen formas muy variadas (estrelladas, redondas...) y no tienen una pared rígida.
*   [ ] Tienen una pared celular gruesa que les da forma geométrica.
*   [ ] Son de color verde porque tienen cloroplastos para fabricar su alimento.
*   [ ] Son las células que forman nuestro cuerpo.
